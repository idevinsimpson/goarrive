## Why the folder exists empty

The governing order for this work is:

```
exact owner boards  ->  complete visual north-star atlas  ->  owner visual review  ->  page-by-page implementation
```

The first step needs files this session cannot produce: they are the owner's,
they are binary, and inventing a stand-in would defeat their whole purpose. The
folder and this README exist so the destination is unambiguous and so nobody has
to guess where to put them.

## What the boards are, and are not

They are a **visual** reference: composition, hierarchy, energy, the feeling of
a native app rather than a responsive website. Every atlas target should inherit
that language — dominant expressive Living WE, navy and green depth, movement at
the centre, celebratory payoff, bottom navigation that reads as app chrome,
fewer card stacks.

They are **not** a data or truth contract. Whatever the boards show, the product
does not gain: a Friends destination, WSF-owned coaching or workouts, named
public contributors without permission, health or happiness claims, public
streak pressure, or a predicted shared total that concurrency cannot support.
Truth and privacy decide *what* a screen shows. The boards decide how it feels.
