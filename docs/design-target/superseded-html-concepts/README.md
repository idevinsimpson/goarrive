# Superseded: the standalone-HTML concept boards

These nine images and the HTML that produced them were the first attempt at a
target package. **They are no longer the target.** The direction is:

> Build the atlas as REAL RN screens/components against the actual WSF design
> system/tokens. Do NOT use standalone HTML as the target. The purpose is to
> prevent another attractive concept that the real product never actually
> becomes.

They are kept rather than deleted because the thinking in them is still useful
for the pages that have no real-RN target yet — the movement picker, the
celebration, the shell board — and because deleting the record of a wrong turn
makes the next person take it again.

## What was wrong with them, beyond the format

The Home concept here paints the **whole page navy**. That is an exploratory
miss. `OWNER-BOARD-2` uses a light ground with the goal hero as the one
dominant navy object, which is what makes the hero read as the important thing
rather than as the screen. Anything reused from this folder must be re-read
against the owner boards first.
