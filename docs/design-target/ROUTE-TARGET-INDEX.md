# Route → target index

Every user-facing route in `apps/westayfit/app/`, mapped to the visual target
that covers it. Generated by reading the route tree at the branch head, not from
memory.

**This index is inventory, not design.** It says what exists and what does not.
It deliberately does not propose targets: the governing order puts the owner
boards first, and they are not present yet (see `owner-north-star/README.md`).

## States

The atlas lists roughly 140 states across §3 A–O. The targets cover the happy
path of five of them. Nothing here should be read as covering a lifecycle or
error state — no target exists for stale progress, unavailable progress, a
refused contribution, a pending or unknown result, a goal closed while
attempting, an expired join code, an offline station, or an unauthorised
display, to name the ones the product already implements and can be seen today.
