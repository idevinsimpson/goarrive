# Single-session video acceptance restriction (local, inactive)

Base is the deployed PR650 source a32b24c96dcd46a91230db5f6693bbe177a0be19. This branch neither merges PR650 nor includes the guest candidate. No runtime environment file, credential, real booking, Zoom allocation or media operation is created by the patch.

The existing WORKOUT_VIDEO_ROLLOUT_ENABLED remains false. Optional server environment WORKOUT_VIDEO_TEST_SCOPE is a strict JSON object containing sessionId, memberUid, memberId (canonical roster ID), coachId, playbookId, workoutId, startsAt and expiresAt (server epoch milliseconds). All IDs must be explicit and the interval must be at most two hours. These are restrictions, not bearer credentials. No values are committed or configured for production.

When scope is absent, existing rollout behavior is unchanged (default off). If scope is present, it takes precedence even over a mistakenly true general rollout: malformed, blank, future or expired scope denies everyone. Only the exact authenticated member UID with member role or actual owning coach UID with coach role can enter the scoped path. Admin impersonation is deliberately not added. Exact session, member, coach, Playbook and pinned workout bindings must match. Existing membership, ownership, policy, time, allocated-room and private recording-off receipt checks all remain required. Scope is an additional admission restriction, not an override of a coach's off policy or recording checks.

Coach setting discovery now sends kind/id and is available only for the two named policy targets. Server writes repeat that restriction and existing ownership validation. Navigation clears prior availability and ignores late approval for another target. The member overlay continues to call its existing availability and explicit-purpose signer; no SDK or media change is introduced.

Admission lease is capped by scope expiry as well as session end and the existing 25-second ceiling. Closing or expiration uses existing polling/teardown. This does not revoke already issued SDK signatures or replace legacy Zoom authorization. Omitted-purpose legacy signer, legacy tile and /join remain unchanged; do not describe this scope as universal Zoom revocation or as a real-device pass.
